## Проект
Telegram-бот @urok_prikolyi_bot: время и погода в Астане, курс биткоина, курсы валют к тенге, случайные цитаты.

Управление:
- Команды (меню задаётся через `setMyCommands` при старте): `/start`, `/help`, `/weather`, `/crypto`, `/rates`, `/quote`, `/time`, `/summary`.
- Кнопки под строкой ввода (Reply-клавиатура): Погода, Крипто, Курсы валют, Цитата, Сводка, Помощь.
- Под ответами inline-кнопка «Обновить» (у цитаты «Другая цитата»), которая правит то же сообщение через `editMessageText`.
- Любое другое сообщение (включая нетекстовые) — полная сводка: время, погода, биткоин, курсы валют.

Каждый блок ответа строится независимо: сбой одного источника не ломает остальные.

## Источники данных (бесплатные, без ключей)
- Погода: Open-Meteo.
- Биткоин (USD, тенге, изменение за 24 ч): CoinGecko.
- Курсы валют (USD, EUR, 100 RUB, CNY к тенге): open.er-api.com, обновляется раз в сутки, рыночный курс, не официальный курс Нацбанка.
- Время: системные часы, фиксированный сдвиг UTC+5 (Казахстан без перехода на летнее время).
- Цитаты: локальный список `QUOTES` в `bot.py` (12 штук).

## Стек
- Python 3.13, библиотеки `requests` и `python-dotenv` (см. `requirements.txt`).
- Прямые вызовы Telegram Bot API (`https://api.telegram.org/bot<token>/METHOD`), без фреймворка.
- Получение обновлений: long polling через `getUpdates` (`allowed_updates`: `message`, `callback_query`), webhook не используется.
- Форматирование ответов: `parse_mode="HTML"`.

## Файлы
- `bot.py` — весь код бота. Блоки: `get_*_text`, `SECTIONS`/`build` (сборка ответов), `BUTTONS`/`COMMANDS`/`resolve` (маршрутизация), `tg` (вызов API), `handle_message`, `handle_callback`, `main`.
- `requirements.txt` — зависимости.
- `.env` — секреты, переменная `BOT_TOKEN`. Исключён через `.gitignore`.
- `.gitignore` — содержит `.env`.

## Запуск
```bash
pip install -r requirements.txt
python bot.py
```
Остановка — Ctrl+C.

## Как добавить новый раздел
1. Написать функцию `get_xxx_text()` в `bot.py`.
2. Добавить её в `SECTIONS` и, при необходимости, в `SUMMARY`.
3. Добавить команду в `COMMANDS` и `COMMAND_KEYS`, кнопку в `BUTTONS` и `MAIN_KEYBOARD`, строку в `HELP_TEXT`.

## Правила
- Токен бота хранить только в `.env`, не выводить в чат, логи или код и не коммитить.
- При старте бот пропускает сообщения, пришедшие, пока он был офлайн (`getUpdates` с `offset=-1`), и отвечает только на новые.
- На каждый `callback_query` обязательно вызывается `answerCallbackQuery`, иначе у кнопки крутится индикатор.
- `getUpdates` и webhook взаимоисключающие: при старте вызывается `deleteWebhook`.
- Одновременно должен работать только один экземпляр бота, иначе `getUpdates` будет конфликтовать.
- Репозиторий: https://github.com/saukum/Dz7urok (публичный, ветка `main`). Перед каждым пушем проверять, что `.env` не в индексе (`git ls-files` не должен его показывать).
